# v0.9.0-rc.13

日期：2026-09-14。分支：`codex/release-v0.9.0`。

## 发布范围

本版本合并当前工作区中的经营报表、个人任务协作、仓库库存、上架运营与库存操作弹窗改动。

- 经营报表拆分五个页签，提供趋势图、筛选表单、明细展开与 CSV 导出；原币和 CNY 本位币分别展示。
- 报表汇总沿用单据历史汇率与费用/结算快照；缺失成本不伪装为零利润，预估费用明确标注。
- 个人协作默认进入任务，合作关系独立成页；库存按商品系列分组。
- 上架运营分别汇总 SKU 与单件的平台在售情况，改善当前 SKU 的操作入口。
- 库存操作弹窗适应短视口，调拨选项展示商品与仓库名称。
