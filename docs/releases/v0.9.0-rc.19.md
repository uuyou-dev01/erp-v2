# v0.9.0-rc.19

日期：2026-09-18。分支：`codex/release-v0.9.0`。

## 改动

- 在工作台的“确认发货”表单增加客户姓名（或平台买家名）、平台订单号、联系电话和收货地址/发货备注。
- 客户姓名为必填项，其余信息按实际订单选填；已有订单信息会自动带入表单。
- 暂存发货草稿和最终确认发货时都会保存客户信息，便于通知、订单与手机端或二手平台记录清晰对应。
- 同步检查了其他 ERP 对话对应的开发分支；相关改动均已包含在当前发布分支，没有额外待合并提交。

## 验证

- 在独立临时 PostgreSQL 17 数据库应用全部 64 个迁移，采购到利润流程测试 16 项全部通过，覆盖暂存及确认发货时的客户信息更新。
- TypeScript 类型检查和生产模式 Next.js 构建通过。
- 本版本无依赖或数据库结构变化，不需要执行数据库迁移。
