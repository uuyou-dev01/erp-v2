# v0.9.0-rc.27

日期：2026-09-30。目标：香港 ERP 测试环境。

## 发布范围

- 售出后继续上架；订单、手机订单和采购报表突出商品及客户信息。
- 期初库存入口收归具体仓库，商品与仓位支持搜索选择；转运列表增加内容、状态筛选和分页。
- 工作量中心增加人员统计和分页；指派执行人后保留侧栏及发货资料草稿。
- 批次转单件按数量生成独立单件、继承成本与来源，修复多件转换数量不一致；加强店铺权限与数量校验。
- 修复混合库存的单件筛选，增加单件入口，仓位导航保留货盘范围。
- 报表以本位币为主，补充原币收入、客单价和折算利润；增加 SKU / 商品组贡献统计及订单利润率。
- 商品经营摘要使用销售匹配的实际成本与汇率计算毛利，兼容历史商品组销售关联。

## 验证与边界

- 相关单元、模拟和源码回归测试通过，类型检查与生产构建通过；桌面和手机统计表交互使用隔离模拟数据验证。
- 本地业务数据库未启动，没有使用真实业务数据执行写入测试。
- 无数据库结构、依赖或新增环境变量变更。
- 箱货拆箱、销售订单及 bundle 的 14 天自动确认收货仍为讨论方案，本次未实现。
- 多币种利润为按订单汇率折算的经营口径，不代表平台实际到账；未确认费用继续标记参考值。
