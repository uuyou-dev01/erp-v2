# v0.9.0-rc.29

日期：2026-10-06。目标：香港 ERP 测试环境。

## 发布范围

- 零库存新品支持预售上架，要求预计发货日及已告知买家的确认；不设置预售数量上限。下单保留承诺快照，补货后分配，实际发货扣库存。
- 工作台增加预售待补货队列及直接分配入口；展示欠货和当前市场现货，完整分配后待确认，未发货逾期进入异常。
- 在途统一统计采购首程、普通转运与已发出集运；扣除已收货数量，保留运单及物流入口，多段运输不重复计量。未接入外部快递实时轨迹。
- 销售页区分待履约预售和已确认销售，分币种列示待履约金额；补货需求计入预售欠货，不提前核算无成本利润。
- 通知显示订单商品名称、数量摘要并支持搜索。
- 合并其他对话已完成的界面优化：工作优先级、紧凑操作布局、搜索和 SKU 上下文保留、盘点字段、币种风险提示、市场参考表达、导航统一及快速录入交互。
- 更新 CLI 商品组与子 SKU 封面说明、帮助和导入示例。

## 范围边界

发货照片删除/拍照问题本轮仅调查。箱货拆箱、14 天自动收货、完整 SKU 归并成本迁移仍未实现。本版不修改历史业务数据或历史币种。
