# v0.9.0-rc.17

日期：2026-09-16。分支：`codex/release-v0.9.0`。

## 改动

- 通知列表把销售订单的客户姓名提升为第一识别信息，同时展示销售平台及平台订单号或系统订单号；已有通知会通过关联订单补齐这些信息。
- Listing 上架管理把状态汇总、地区、平台、搜索、风险与排序合并进同一个表格容器，减少筛选区与表格之间的空白和重复边框。
- 筛选结果为空时仍保留完整筛选表头，用户可以直接调整条件，不会陷入只有空状态、无法返回的页面。

## 验证

- TypeScript 类型检查、Prettier 和生产模式 Next.js 构建通过；构建只保留仓库既有的未使用变量警告。
- 使用本地真实页面分别检查 Listing 和通知页，确认表头合并、客户姓名层级、平台订单信息及现有操作均正常。
- 本版本无依赖或数据库结构变化。
