# v0.9.0-rc.20

日期：2026-09-19。分支：`codex/release-v0.9.0`。

## 改动

- 发货协作任务进入页面、打开任务、切回页面及上传/保存结束时获取最新资料，不进行定时轮询。
- 资料区增加“更新资料”按钮、更新状态和失败重试提示。
- 同步远端图片增删和未编辑字段，保留正在填写的运单号、备注等草稿；切换任务或执行权限变化时重置表单。
- 请求进行期间触发的新动作会合并排队，避免漏掉任务切换后的更新；旧任务或上传前的响应不会覆盖当前内容。
- 通知铃铛保留原有定时更新行为。本次不修改数据库结构或依赖。
