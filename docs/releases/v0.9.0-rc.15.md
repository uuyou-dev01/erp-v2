# v0.9.0-rc.15

日期：2026-09-14。分支：`codex/release-v0.9.0`。

## 改动

- 上架管理列表和库存视图中的「修改/编辑」改为紧凑弹窗，可就地修改平台售价、币种和上架日期。
- Listing 详情页保留查看信息，移除占据整页宽度的编辑卡片，并在页头提供相同弹窗入口。
- 仅在上架日期实际变化时更新该字段；只修改售价或币种时保留原始上架时间。无效日期会被拒绝。

## 验证

- TypeScript 类型检查、ESLint 和生产模式 Next.js 构建通过；构建仅保留仓库既有的未使用变量警告。
- 隔离 PostgreSQL 测试库中的 Listing 相关 11 项测试通过，包含上架日期更正、原始时间保留与无效日期拒绝。
- 在隔离测试库登录实际页面，桌面与手机截图核对弹窗尺寸和字段；实际修改上架日期后列表立即显示新日期。
- 本版本无依赖或数据库结构变化。
