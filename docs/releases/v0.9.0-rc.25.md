# v0.9.0-rc.25

日期：2026-09-20。分支：`codex/release-v0.9.0`。

## 改动

- 左侧导航底部新增可随时打开的售价计算器；商品详情的经营摘要和库存与上架页可带入当前规格进价、成交参考。替换原有大块定价表单。
- 默认目标利润率 30%，提供基础估价、含 10% 平台费预设和 20% / 30% / 40% 利润率快捷值；支持费用、币种、汇率调整、复制售价、清空重算。预设不代表平台实际收费。
- 关闭与站内换页保留本次测算，切换店铺清空；测算不会修改档案或实际上架价。跨币种需明确汇率，同币种参考价与目标利润售价取较高者。
- 库存详情新品库存区新增当前规格最近成交单价、币种、日期和平台；打开详情时加载，无成交和加载失败分别提示。按有效订单日期查询全部市场历史，排除单件及实物全退，保留原成交单价，不冒充售后净收入。

## 验证

- 定价算法、计算器草稿、成交价与权限范围共 30 项测试通过（模拟数据，不连接真实数据库）。
- 类型检查、生产构建通过；预览验证了带入进价、费用与汇率联动、预设切换、关闭后通过全局入口继续计算。
- 无数据库结构、依赖或新增环境变量变更。
