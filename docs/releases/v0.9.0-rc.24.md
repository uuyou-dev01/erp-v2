# v0.9.0-rc.24

日期：2026-09-20。分支：`codex/release-v0.9.0`。

## 改动

- 库存列表显示规格销量与补货预警，保留近期销售后已售罄的规格；经营池按商品组展示、筛选计数和整组分页，展开查看具体规格。
- 补货按规格、市场和仓位独立计算，销量扣除实际退货，明确交期与有效到货抵扣；样本不足不估算精确采购量，停用和中古规格不自动建议采购。
- 经营池显示建议采购时间、数量及计算依据；登记采购仅预填表单，不自动提交。
- 库存列表规格、平台状态及操作区改为紧凑布局，保留缺货预警、规格选择和平台待上架入口；商品资料的子规格行缩小字号和留白。

## 本地验证

- 补货、分组、库存筛选等 88 项定向测试通过；平台摘要、上架交互与分组等 40 项测试通过（两组包含部分重复用例）。
- 类型检查和生产构建通过。没有数据库结构、依赖或新增环境变量变更。
- 模拟数据浏览器验证了分组展开、每页 25 个商品组、筛选合计、售罄与小样本提示、采购链接、规格切换及平台展开。
- 同类两规格、八平台商品行由 193.5px 压缩到 113px；1536、1280、820、390px 宽度无页面横向溢出。
- 本机真实数据库集成测试未执行；模拟数据验证不替代服务器真实查询核验。
