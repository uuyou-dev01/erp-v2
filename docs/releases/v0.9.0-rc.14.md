# v0.9.0-rc.14

日期：2026-09-14。分支：`codex/release-v0.9.0`。

## 改动

- 已发货、未结算的普通销售订单可在订单页更正原币；售价、平台费、销售运费的数字不变，报表按订单日汇率重新折算。操作需要确认费用币种，并记录前后数据。存在结算、财务关联或独立费用明细时拒绝直接更正。
- 经营报表销售明细改为优先显示成交时间与商品数量，展开后可查看 SKU、原币行金额、单价及订单号；搜索与 CSV 导出包含商品和时间。
- 集运批次在未封箱时可移出误加的采购商品，并将对应起运仓库存恢复为可用；库存数量、状态、占用或其他批次关联不匹配时拒绝撤销。
- 线上发现的一笔误录币种订单已单独核实和修正，成交额、平台费与预估运费均按 JPY 原币解释；这项数据修正不依赖本版本上线。

## 验证

- TypeScript 类型检查和 ESLint 通过。
- 生产模式 Next.js 构建通过；仅保留仓库既有的未使用变量警告。
- 使用隔离 PostgreSQL 测试库运行经营报表、订单币种更正和集运撤销共 21 项测试通过。
- 浏览器截图核对经营报表、集运批次与币种更正弹窗。
- 本版本无数据库结构迁移。
