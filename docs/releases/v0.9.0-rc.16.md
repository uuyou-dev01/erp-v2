# v0.9.0-rc.16

日期：2026-09-14。分支：`codex/release-v0.9.0`。

## 改动

- 「我的任务」发货列表改为紧凑摘要，只显示商品、SKU、件数、状态和时效；订单号、仓库及详细时间保留在任务详情中。
- 页面进入时不再自动展开第一项。点击摘要才在下方显示详情，再次点击可收起；手机端点选后会滚动到详情。带 `task` 参数的链接仍会直接打开指定任务。
- 桌面端未选任务时显示选择提示；仓库工作台原有的详情抽屉和任务操作保持可用。
- 更新端到端测试以检查手机端摘要高度、收起和展开行为，并收窄几个已有流程测试的元素定位。

## 验证

- TypeScript 类型检查、ESLint、Prettier 和生产模式 Next.js 构建通过。
- 隔离 PostgreSQL 环境中的仓库协作源测试 4 项通过；外部仓库协作与隐私保护端到端测试 2 项通过。
- 使用实际页面在 390px 手机宽度下截图核对：[收起的任务列表](../testing/releases/v0.9.0/screenshots/10-04a-compact-mobile-task-list.png)、[点选后的详情](../testing/releases/v0.9.0/screenshots/10-04b-mobile-task-detail.png)。
- 本版本无依赖或数据库结构变化。
