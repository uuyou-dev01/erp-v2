# v0.9.0-rc.28

日期：2026-10-04。目标：香港 ERP 测试环境。

## 发布范围

- 新增 AI 商品调查 CLI：查询分类与商品、上传图片、预检并一次创建商品组及规格，或独立 SKU。
- 参考售价、目标进货价保留原币种；有来源和观察时间的调查价格写入企业内商品情报，不产生库存和交易。
- 网页和 CLI 共用商品身份、编码及校验规则；同一导入标识支持重试去重，冲突不覆盖，失败整体回滚。
- 默认返回精简 JSON；完整规格结果按需返回。内部导入标识不会显示为商品属性，网页编辑后仍保留。
- 发布镜像包含 CLI、使用文档及示例。独立 Compose `cli` 服务通过 HTTPS 访问 ERP，不注入数据库或应用密钥；登录配置保存在持久目录。

## 本地验证

- 20 个相关测试文件、121 项回归测试通过。
- 真实 CLI → HTTP → 隔离数据库全流程通过，包括登录、权限、图片上传、预检、导入、重试、冲突及会话撤销。
- 类型检查与生产构建通过；构建仅有现存未使用变量警告。
- 无依赖或数据库结构变更。第一版仅新建，不通过 CLI 覆盖已有商品。
