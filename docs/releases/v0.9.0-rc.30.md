# v0.9.0-rc.30

日期：2026-10-07。目标：香港 ERP 测试环境。

## 发布内容

- 零库存详情弹窗补齐预售上架入口，默认开启预售，保留交期与买家告知确认。
- 同平台、同账号、同币种的预售新品可以与现货合包；买家确认等齐后发货。现货只预留，预售缺货进入待补货，全部分配到共同仓后才能确认并整单发出。
- 工作台待补货增加取消入口；取消释放预留、关闭任务，不自动重建平台上架或执行平台退款。
- 共同发货仓在订单和工作台展示，分配和发货均校验该仓；工作台现货提醒只统计尚欠货的 SKU。
- 关闭当前 Listing 的预售后恢复普通逐件售出，既有订单交期不变。

## 数据与验证

新增迁移 `20261007090000_presale_bundle`，仅增加可空字段 `customer_orders.shipTogetherLocationId`，不改历史记录。

本地 168 个测试文件、812 项测试全部通过，类型检查通过。生产模式浏览器验收包含零库存详情入口、混合下单、工作台取消；连同登录准备 2 项通过。

部署前备份恢复验证、候选镜像检查和上线结果在发布后补录。回退应用不删除新增字段；如产生预售合包订单，回退后须暂停此类订单确认发货，旧版没有共同仓约束。
