# v0.9.0-rc.18

日期：2026-09-16。分支：`codex/release-v0.9.0`。

## 改动

- 普通销售订单在“已成交、待发货”阶段即可使用“更正币种”，无需为了修正录入错误而提前确认发货。
- 更正仍只改变订单原币标签，售价、平台费和销售运费数值保持不变；操作同步快速录入记录并写入修改前后值审计日志。
- 已结算、代卖、代发、售后或已有下游财务关联的订单继续禁止直接更正币种。
- Listing 上架管理进一步压缩表头：状态汇总并入标题行，地区、平台、搜索、风险和排序合并为一条紧凑工具栏。

## 验证

- TypeScript 类型检查、Prettier、生产模式 Next.js 构建通过。
