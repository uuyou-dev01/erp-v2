# 货盘分销系统（待实施）

## 业务需求

货盘分销系统是一个B2B分销平台，允许用户将自己采购的货物发布到公共市场，供其他用户浏览和联系购买。

### 核心场景

**卖家视角**：
- 买了一批货想分销
- 登录系统，进入分销板块
- 发布货盘信息（商品、价格、照片、联系方式）
- 等待买家联系

**买家视角**：
- 浏览公共分销市场
- 看到感兴趣的货盘
- 下载照片、查看联系方式
- 直接联系卖家洽谈

### 关键特征

1. **多租户隔离**：每个Store（账户）有独立的私有库存ERP
2. **公共市场**：所有用户都能看到所有货盘
3. **不转移所有权**：发布货盘不转移库存所有权
4. **信息透明**：显示卖家联系方式和上架人信息
5. **自由交易**：平台只提供信息展示，交易线下完成

## 数据模型设计

### 核心表结构

#### MarketplaceListing（货盘表）
- 卖家信息：Store、联系方式、上架人
- 货盘信息：标题、描述、分类、标签
- 库存关联：关联的Lot/ItemUnit
- 价格信息：批发价、建议零售价、最小起订量
- 商品信息：照片、所在地、物流信息
- 状态管理：ACTIVE/SOLD_OUT/DELISTED
- 统计数据：浏览量、感兴趣人数

#### MarketplaceInterest（感兴趣标记）
- 买家Store和User
- 关联的货盘
- 备注信息

#### MarketplaceInquiry（咨询留言）
- 询问方信息
- 留言内容
- 是否公开显示

## 技术实现要点

### 架构设计
- 私有ERP：Store级别数据隔离
- 公共市场：跨Store的MarketplaceListing
- 不锁定库存：发布时只记录关联关系
- 异步同步：定期检查库存可用性

### 权限控制
- 浏览市场：所有登录用户
- 发布货盘：需要库存管理权限
- 编辑/下架：只能操作自己的货盘
- 查看联系方式：所有登录用户

### 性能优化
- 数据库索引：status, category, publishedAt
- 分页加载：每页20-50条
- 图片优化：缩略图 + 原图
- 缓存策略：热门货盘缓存

### 安全考虑
- 联系方式脱敏：138****1234
- 防刷机制：浏览量、感兴趣
- 图片限制：大小、格式
- 敏感词过滤：标题、描述

## 业务规则

### 库存同步策略
1. **发布时**：检查库存是否足够，不锁定
2. **库存变化时**：不自动更新货盘
3. **定期检查**：每日检查库存可用性
4. **手动下架**：卖家自行管理货盘状态

### 联系方式显示
1. **列表页**：不显示联系方式
2. **详情页**：脱敏显示（138****1234）
3. **点击查看**：完整显示
4. **记录日志**：记录查看行为

### 照片管理
1. **来源**：可以使用ItemUnit照片或单独上传
2. **格式**：JPG/PNG，最大5MB
3. **数量**：最多20张
4. **下载**：支持批量下载ZIP
