# 手机经营入口改进（2026-09-21）

## 当前实现

- 底部导航：今天、在售、记一笔、库存、报表。账号和通知保留在首页右上角。
- 今天：采购、售出、补费用、最近订单四个快捷入口；只统计手机可执行的今日任务，与待办页一致。
- 在售：搜索商品/平台，在售、售完、下架筛选；复用快速售出及下架动作，售出后打开手机销售详情。ERP 下架不会自动操作第三方平台。
- 采购：已有商品选择与新商品创建；供应商、外部订单号和物流折叠；保留采集草稿恢复。
- 最近订单：采购/销售切换，按最近更新排序，搜索订单号、商品或交易对象，最多显示 50 条。
- 采购详情：物流补录、整单收货、采购费用清单编辑。带入已有费用与原商品分摊金额；订单版本冲突时拒绝覆盖。特殊费用类型转完整订单处理。
- 销售详情：核对售价、实际邮费、平台手续费并结算利润，链接发货待办和完整售后页面。
- 零散费用：按当前经营主体保存费用子账草稿；具有防重复标识及当前会话草稿恢复。明确未登记付款，不重复计入原单邮费。
- 库存：按仓库及关键词查询、逐项盘点差异确认、记录原因，复用库存补录和仓间调拨。
- 报表：今天、本月、上月；销售额、订单利润、采购金额、待收结算及可点击的明细。沿用经营报表币种和时间口径，标明预估费用。
- 消息：全部、未读、已读筛选；强化未读背景；处理已读接口失败。

## 验证与边界

- 生产构建使用独立目录 `.next-mobile-verify`，开发预览使用 `.next-mobile-dev`，避免两者互相覆盖缓存。
- 无数据库单元测试覆盖费用防重、认证、费用版本冲突及现有报表/库存/采集等规则。
- 数据库集成测试需要配置独立 `TEST_DATABASE_URL`；本轮没有使用业务数据库执行测试写入。
- 浏览器核查首页、在售/售出弹窗、库存、报表、订单列表及采购费用入口，不提交真实销售或库存变更。
- 取消、退款、质检和费用确认仍通过已有完整业务页面处理；手机收货当前是整单收货，不支持在简化表单中直接处理分批或少件。
- 尚无独立资金流水登记或第三方平台自动下架。费用保存与订单结算都不等同于资金已到账/已支付。
