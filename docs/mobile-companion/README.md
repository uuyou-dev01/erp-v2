# ERP 随身助手

状态：Web/PWA 全链路及商品链接读取已实现，生产环境配置与真机 UAT 待执行
最后更新：2026-08-09

## 一句话定位

ERP 随身助手是现有 ERP 的独立移动执行端，不是 PC ERP 的响应式版本。

它只解决两个高频场景：

1. **商品与价格采集**：在闲鱼、千岛、微信等移动场景中，快速保存市场价格或登记真实购入。
2. **日常任务执行**：在手机上查看自己需要处理的节点，完成到货、分流、入库、委托、发货、妥投、退货检查和异常确认。

PC 继续负责主档、配置、复杂查询、批量处理、财务和经营分析；手机负责采集、扫码、拍照、补充少量字段和确认下一节点。

## 核心产品原则

1. **不是缩小版 ERP**：不复制 PC 的侧边栏、表格和模块导航。
2. **任务驱动**：首页回答“现在轮到我做什么”，而不是“系统有哪些模块”。
3. **一次只做一个动作**：每个移动页面只承载一个明确的业务确认。
4. **业务成功才完成任务**：不能把“任务已完成”和“业务状态已更新”拆成两个互不关联的操作。
5. **采集不等于入库**：手机登记已购买后进入采购/在途流程，到货确认后才形成库存。
6. **证据优先**：截图、链接、图片、扫码结果和人工输入都保留来源。
7. **自动提取必须可确认**：OCR/AI 负责建议，价格、币种、数量、SKU 和高风险状态必须由人确认。
8. **高风险动作更严格**：取消、退货、库存调整和结算要求原因、二次确认和完整审计。

## 两条业务主线

### 主线 A：商品与价格采集

```text
分享链接 / 文字 / 截图 / 手动输入
→ 保存原始 Capture
→ 提取平台、商品、规格、成色、价格、币种和数量
→ 用户选择“记录价格”或“已经购买”
→ 记录价格：SourceListing / Snapshot / Observation
→ 已经购买：价格观察 + QuickEntry + 采购单/采购明细
→ 到货任务
→ 分流/入库
→ 正式库存
```

### 主线 B：移动任务执行

```text
业务状态产生下一节点
→ 生成或关联 Task
→ 指派给负责人
→ 手机首页/推送提醒
→ 负责人扫码、拍照、填写必要字段
→ 提交业务动作
→ 领域事务更新业务状态与账本
→ 写入 DOMAIN_COMPLETED 恢复点并收尾 Task/日志/通知
→ 通知委托人或下一负责人
```

## 已交付入口

- `/m`：移动“今天”首页。
- `/m/tasks`：我的、待领取、我委托、已完成任务。
- `/m/capture/price`：市场价格采集。
- `/m/capture/purchase`：单行或多行真实购入登记。
- `/m/prices`：来源商品价格变化。
- `/m/tasks/batch`：同类节点批量执行。
- `/m/tasks/ship`：连续扫码发货。
- `/m/notifications`：站内通知、已读与任务深链。
- `/m/me`：设备、PWA 与推送设置。
- `/product-intelligence/captures`：PC 端采集箱与人工确认。
- `/product-intelligence/price-changes`：PC 来源价格变化。

移动端使用独立路由组、应用壳和 API，不渲染 PC ERP 的侧边栏、宽表格或完整功能树。

## 与现有系统的关系

现有系统已经具备可复用的业务基础：

- `ProductIntelligenceItem` / `ProductIntelligenceObservation`：标准商品情报与价格观察。
- `QuickEntry`：采购、物流、库存和销售的快速录入桥梁。
- `PurchaseOrder` / `PurchaseLine`：正式采购对象。
- `Task`：负责人、委托人、截止时间和完成状态。
- `Notification`：任务指派与完成通知。
- `ActivityLog`：业务操作审计。
- `WORKFLOW_ACTION_SPECS`：当前节点允许执行的业务动作及字段。

移动端只增加独立的呈现层、移动 API、设备/推送能力和必要的来源关联，不复制采购、库存、订单或任务领域逻辑。

## 当前交付范围

当前版本已经交付以下闭环：

1. 独立移动端登录与店铺选择。
2. “今天”首页、我的任务、我委托的。
3. 补采购物流、确认到货、委托、确认发货。
4. 拍照上传、扫描/粘贴运单号。
5. 手机手动登记“记录价格”或“已购买”。
6. 已购买生成真实购入价观察和 QuickEntry。
7. 站内通知、深链和可选 Web Push。
8. 截图上传、中文/日文/英文 OCR 和价格候选确认。
9. PWA 安装、Web Share Target、离线采集草稿、设备撤销。
10. 价格与购入表单可读取 Mercari、Atmos 等公开商品链接，回填平台、商品名、价格、币种、成色和外部商品 ID。

手机端与 PC 的职责边界：手机一次读取一个链接，并可继续拍照/OCR 或补充缺失字段；PC 采集箱负责最多 12 条链接的批量解析、批量核对，以及商品主档和采购的集中整理。闲鱼等登录后信息不完整的平台继续以分享链接、截图和人工确认为主，不尝试绕过平台保护。

第一版不包含复杂 SKU 建档、完整商品情报自动匹配、批量库存修改、财务配置、报表和后台爬虫。

## 本地运行与验收

```bash
npm run db:generate
npm run db:migrate
npm run dev
```

访问 `http://localhost:3000/m`。完整自动化验收使用：

```bash
npm run verify
```

Web Push 为可选能力，需要配置 `.env.example` 中的 VAPID 参数。开发环境附件保存在 `.data/mobile-assets` 并通过鉴权接口读取；生产环境应把同一上传合约替换为私有 S3-compatible 对象存储。
