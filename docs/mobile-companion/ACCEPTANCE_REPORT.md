# ERP 随身助手实施验收报告

日期：2026-08-01
结论：Web/PWA 全链路通过；生产发布只剩供应商凭据、调度配置和真机业务验收。

## 1. 两条主线

### A. 价格与购入

- 支持闲鱼、千岛、微信等来源的链接、文字、截图和手动输入。
- “记录价格”保存 Capture、来源商品/快照和价格 Observation；未匹配 SKU 时进入 PC 采集箱。
- “已购买”支持多行、订单号、卖家、日期、运费、币种和物流信息，生成真实购入观察、QuickEntry 与采购对象。
- 购入登记不会直接增加库存；必须继续完成到货、分流和入库节点。
- 支持确定性 URL 归一化、来源去重、请求幂等和原始证据反查。
- 截图 OCR 支持中文、日文和英文；多金额只提供候选，由用户确认。
- 正式 SKU 搜索支持条码、款号、编码、别名、品牌、名称与规格评分，并展示百分比和理由。
- 手机选择的 `skuId` 原样进入 Capture、Observation、QuickEntry 与采购行；E2E 已证明不会重复建 SKU。
- PC 采集审核支持接受、拒绝和重新匹配，接受结果沉淀为可复用别名。
- 同一来源再次采集时自动生成价格差额与变化率，手机和 PC 均可查看。

### B. 日常执行

- 独立“今天/待办/采集/我的”移动信息架构，不复用 PC 页面。
- 支持我的任务、待领取、我委托、已完成回执、领取、开始、指派、截止时间和备注。
- 支持补物流、到货、分流、入库、确认订单、发货、妥投、登记退货和退货检查。
- 发货和退货要求凭证与二次确认；部分到货要求图片。
- 业务成功后完成关联任务并写审计；失败不完成任务。
- 站内通知支持未读、全部已读和任务深链；Web Push 未配置时自动降级为站内通知。
- 支持 1–20 条批量现场处理与连续扫码发货。
- 通知支持去重、outbox 重试、静默时段、每小时和每日汇总。

## 2. 安全与一致性

- 移动写操作要求已登录且设备有效；设备可撤销。
- API 重新校验组织、店铺、用户、任务和附件归属。
- `Idempotency-Key` 防止重复执行；相同键不同请求返回冲突。
- `expectedVersion` 防止他人已处理后覆盖新状态。
- 附件限制图片类型与 8 MB 大小，校验 SHA-256；开发文件位于 `.data/mobile-assets`，通过鉴权接口读取，不暴露公共目录。
- Service Worker 不缓存业务页面或敏感 API，仅缓存图标和离线说明页。
- 生产可切换 S3/R2/MinIO 预签名上传；本地开发继续使用私有 `.data` 目录。
- 数据库级按设备限流、功能开关、数据保留脚本和受密钥保护的健康接口已落地。

## 4. 生产发布前检查

1. 执行 Prisma migrations，并设置正式域名/会话密钥。
2. 配置私有 S3-compatible 存储；代码已支持 AWS S3、R2 和 MinIO。
3. 如启用 Web Push，配置 VAPID 公私钥与联系人，并在目标 iPhone/Android 上授权测试。
4. 用真实角色、真实地点和真实单据完成至少一轮到货、入库、发货和退货真机验收。
5. 确认截图保留期、静默/汇总默认值和高风险动作权限策略，并配置通知与保留任务调度。

这些项目依赖部署环境或业务决定，不阻塞当前代码基线验收。
