# ERP 固定托管拓扑

## 业务约定

ERP 借用公寓业务持有的 `lianyuapt.com` 域名，但 ERP 与酒店系统是两个独立服务。域名归属不能用于推断服务器归属。

ERP 需要同时供东京和中国内地使用，因此固定托管在阿里云香港节点。

## 强制边界

1. ERP 的应用、PostgreSQL、资产、备份、迁移、反向代理和证书均部署在香港实例。
2. 杭州实例仅用于酒店系统；ERP 发布不得占用或修改其 Nginx、数据库和业务服务。
3. 每次部署前必须同时核对实例 ID、地域和公网 IP，不能只根据域名或控制台标签判断目标。
4. `erp-test` 的 DNS A 记录应指向 `47.243.87.184`；`lianyu-test` 保持指向 `47.98.181.237`。
5. ERP 容器仅向宿主回环地址发布应用端口；公网只开放 80/443，由宿主反向代理终止 HTTPS。
