## ui.md

### UI 规范（基于 shadcn/ui）

#### 设计目标
- 操作清晰
- 状态明确
- 风险可见（库存/超卖/待下架）

---

### 一、页面结构规范

#### 页面类型
1. List Page（列表）
- 表格为主
- 支持筛选 / 排序 / 快捷操作

2. Detail Page（详情）
- 分区展示（信息 / 动作 / 历史）

3. Action Modal（动作弹窗）
- 明确影响范围
- 必须展示关键后果（扣库存 / 分摊）

---

### 二、库存相关 UI 约束
- Allocation 操作必须可视化
- 拆分（Split）必须二次确认
- ItemUnit 必须展示照片与成色

---

### 三、状态驱动 UI
- CONFIRMED 前：允许修改
- CONFIRMED 后：只读 + 审计
- 危险操作高亮提示

---

### 四、组件使用原则
- 优先使用 shadcn/ui
- 不自造基础组件
- 所有业务操作封装为 Feature Component
