# 报表分析模块

## 模块概述

报表分析模块提供业务数据的可视化分析，帮助用户了解业务运营状况，做出数据驱动的决策。

## 核心功能

### 1. 业务概览（Dashboard）
- 关键指标卡片
- 趋势图表
- 快速洞察

### 2. 库存报表
- 库存价值分析
- 库存周转率
- 库存预警
- 库存分布（按位置、SKU、状态）

### 3. 采购报表
- 采购金额统计
- 供应商分析
- 采购趋势
- 成本分析

### 4. 销售报表
- 销售额统计
- 订单分析
- 平台对比
- 利润分析

### 5. 上架报表
- 上架商品统计
- 平台分布
- 上架效率
- 转化率分析

## 报表类型

### 实时报表
- 基于当前数据库状态
- 实时计算
- 适用于：库存查询、订单状态

### 统计报表
- 基于历史数据聚合
- 定期计算（每日/每周/每月）
- 适用于：趋势分析、对比分析

### 预测报表
- 基于历史数据预测
- 使用统计模型
- 适用于：补货建议、销售预测

## 数据模型

### ReportSnapshot（报表快照）
```prisma
model ReportSnapshot {
  id          String   @id @default(cuid())
  storeId     String
  reportType  String   // INVENTORY, SALES, PROCUREMENT, LISTING
  period      String   // DAILY, WEEKLY, MONTHLY
  periodStart DateTime
  periodEnd   DateTime
  data        Json     // 报表数据
  createdAt   DateTime @default(now())
  
  @@index([storeId, reportType, periodStart])
  @@map("report_snapshots")
}
```

## 报表指标

### 库存指标
- **库存总值**：所有库存的成本总和
- **可售库存值**：AVAILABLE状态库存的成本总和
- **库存周转率**：销售成本 / 平均库存
- **库存天数**：365 / 库存周转率
- **滞销库存**：超过N天未售出的库存

### 采购指标
- **采购总额**：采购订单总金额
- **平均采购价**：总金额 / 总数量
- **供应商数量**：活跃供应商数
- **采购频率**：采购订单数 / 时间周期
- **采购完成率**：已收货订单 / 总订单

### 销售指标
- **销售额**：订单总金额
- **订单数**：订单总数
- **客单价**：销售额 / 订单数
- **毛利率**：(销售额 - 成本) / 销售额
- **订单完成率**：已完成订单 / 总订单

### 上架指标
- **上架商品数**：ACTIVE状态的listing数量
- **平台覆盖率**：已上架平台 / 总平台
- **上架转化率**：销售订单 / 上架商品
- **平均上架价**：所有listing的平均价格

## 图表类型

### 1. 卡片指标（Card Metrics）
- 单一数值展示
- 环比/同比变化
- 趋势指示器

### 2. 折线图（Line Chart）
- 时间序列数据
- 多指标对比
- 趋势分析

### 3. 柱状图（Bar Chart）
- 分类对比
- 排名展示
- 周期对比

### 4. 饼图（Pie Chart）
- 占比分析
- 分布展示
- 构成分析

### 5. 表格（Table）
- 明细数据
- 多维度展示
- 可排序/筛选

## 权限控制

### 查看权限
- 所有用户可查看本Store的报表
- 不同角色可能有不同的报表访问权限

### 数据隔离
- 所有查询必须包含storeId
- 跨Store数据不可见
- 敏感数据脱敏

## 性能考虑

### 大数据量处理
- 分页查询
- 数据采样
- 预聚合
- 后台任务

### 响应时间目标
- 卡片指标：< 500ms
- 图表加载：< 1s
- 表格加载：< 2s
- 导出报告：< 5s
