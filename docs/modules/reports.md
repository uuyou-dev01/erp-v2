# 经营报表模块

最后更新：2026-09-14。

## 当前实现

入口 `/reports`，由 `requireUserContext()` 取得已授权的店铺及主体。店铺业务数据与主体费用子账明确分开。现有工作量、团队绩效仍为独立页面。

| Tab        | 内容                                                           | 明细入口               |
| ---------- | -------------------------------------------------------------- | ---------------------- |
| 经营总览   | 销售、贡献利润、采购、当前库存；趋势及利润拆解；渠道及运营概况 | 指标卡片进入对应 Tab   |
| 销售与利润 | 月度对账、原币核对、渠道对比、订单明细                         | 核算细节及销售订单     |
| 采购与库存 | 采购统计、当前仓库分布、采购及库存明细                         | 采购单、库存批次、单品 |
| 费用分析   | 平台费、销售运费、代理手续费预估、实际物流费、主体费用         | 销售、物流、费用子账   |
| 代卖结算   | 已确认应收/应付、已收/已付、草稿及单据明细                     | 结算单                 |

支持本月、上月、本季度、自定义起止日期（最多 366 天跨度）。Tab 和期间可由 URL 恢复；Tab 固定在滚动区域顶部。明细可按文字、原币、状态筛选，每页十条。汇总及筛选后的明细分别导出 UTF-8 CSV。

销售明细优先显示商品名、件数、北京时间的成交时刻和渠道，单据号作次要标识。展开可核对各商品的原币行金额/单价、汇率与成本；搜索匹配商品名/SKU，导出保留成交时刻和商品行。未结算的已发货普通订单可在订单页“更正币种”修正原币标签，售价、平台费和销售运费数值保持不变，要求用户确认三者同币，并在事务内校验没有结算、售后、渠道对账、钱包等下游财务记录，同时写入前后值审计日志。金额录错仍通过“结算订单”修正；已结算或多币费用需另行核对，避免以另一币种数字覆盖当前币种。

## 统计口径

- **统一本位币：CNY**，沿用 `lib/fx.ts` 的项目约定。原币显示 ISO 币种代码，避免 JPY/CNY 都使用 ¥ 的歧义。
- **换算：** 原币 × 兑 CNY 汇率。销售与订单费用按订单日期，库存及分配成本按库存成本币种和入库/建档日期。采购优先单据约定汇率；结算及确认费用优先已保存的 CNY 金额和对应汇率快照。
- **精度：** Decimal 运算；每笔折合至两位后汇总，卡片、图、表共用同一结果。未知金额传播为 `null`，界面显示“待核算”，不输出假零或部分合计。
- **销售收入：** CONFIRMED / SHIPPED / DELIVERED 订单的 totalPaid。未成交、取消、整单退货不纳入。
- **订单贡献利润：** 销售收入 − 库存分配成本 − 平台费 − 已录入销售运费。分配不完整、库存成本未确认或换算失败时利润待核算；运费不是 ACTUAL 时为参考值。
- **代理手续费：** 订单金额 × shippingProviderFeeRate 的预估值，单列展示，不当作确认费用扣减利润。
- **采购：** 依据 orderedAt（缺失时使用 createdAt），排除草稿和取消。
- **库存：** 当前 ACTIVE 批次的正数账面结存 × 单位成本，加 AVAILABLE 单品成本；不含已分配单品、在途/集运状态。仓库表和总览口径一致，不随期间过滤入库日期。
- **时间：** Asia/Shanghai，起止日期包含完整结束日；月度分组使用相同日界线。
- **费用子账：** 当前主体范围，按发生日期。ACTUAL 且 CONFIRMED / PARTIALLY_SETTLED / SETTLED 才计确认应收应付；内部双向身份中性化。确认额不等于未结余额。
- **结算：** 按创建期间，分别汇总 PAYABLE、RECEIVABLE。草稿不计已确认待结算；VOID 与 INFORMATIONAL 不计金额。已付/已收为单据状态统计，不是现金流水报表。

贡献利润不等于企业净利润。物流支出、主体费用与订单成本可能重叠，独立列示，不直接相加；不自动计算税费及汇兑损益。尚不提供期间末历史库存估值、完整企业损益表或现金流量表。

## 实现位置

- `app/(dashboard)/reports/page.tsx`：认证范围与期间解析。
- `lib/application/operating-report.ts`：业务明细、逐笔换算及汇总。
- `lib/application/operating-report-math.ts`：日界线、日期校验、金额计算与 CSV 转义。
- `components/reports/operating-dashboard.tsx`：五个分类面板与总览。
- `components/reports/report-detail-table.tsx`：筛选、分页、核算展开、CSV。
- `components/reports/report-primitives.tsx`：共用指标、区域与金额显示。
- `components/reports/operating-trend-chart.tsx`：期间收入/成本/利润图。
- `components/reports/date-range-picker.tsx`：快捷期间与日期表单。

原 `app/actions/reports.ts` 的统计函数仍保留给既有调用方；新版 `/reports` 使用新的统一数据查询，避免多个独立聚合口径漂移。数据按页面请求计算；明细目前为客户端筛选分页，尚未实施大规模预聚合及服务端游标分页。
