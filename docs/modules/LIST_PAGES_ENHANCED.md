## 设计模式

所有列表页面遵循统一的设计模式：

1. **页面头部**：标题 + 描述 + 新建按钮
2. **统计卡片区域**：4个卡片展示关键指标，带图标和颜色
3. **列表卡片**：
   - 卡片标题 + 搜索框
   - 空状态：图标 + 提示文字 + 操作按钮
   - 数据表格：完整的列信息 + 操作按钮

## 技术细节

- 使用 Lucide React 图标库
- 使用 shadcn/ui 组件库
- 统计数据在服务端计算
- 搜索框为前端占位（后续可实现客户端过滤）
- 所有日期使用 `zh-CN` 本地化格式
- 彩色标签使用自定义 Tailwind 类
