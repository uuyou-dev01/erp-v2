## 模块概述

报表分析模块提供业务数据的可视化分析，包括库存、采购、销售、上架等核心业务指标的统计和图表展示。

## 报表指标

### 业务概览指标
1. **库存总值**：所有活跃库存的成本总和
2. **采购总额**：所有采购订单的总金额
3. **销售总额**：所有销售订单的总金额
4. **上架商品**：活跃状态的listing数量

### 库存分析指标
1. **按位置分布**：各仓库位置的库存价值
2. **按状态分布**：活跃、可用、已分配、已消耗的数量

### 销售分析指标
1. **按月趋势**：每月销售额的时间序列
2. **按状态分布**：草稿、已确认、已发货、已送达的订单数

### 数据查询

```typescript
// 示例：获取库存总值
const inventoryLots = await prisma.inventoryLot.findMany({
  where: { storeId, status: "ACTIVE" },
  select: { unitCost: true },
});

const totalValue = inventoryLots.reduce(
  (sum, lot) => sum.plus(new Decimal(lot.unitCost.toString())),
  new Decimal(0)
);
```
