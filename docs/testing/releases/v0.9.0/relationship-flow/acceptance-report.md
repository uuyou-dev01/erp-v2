# 任务邀请到长期合作验收报告

结论：通过。被邀请人现在有明确的个人身份、任务角色、默认入口和长期发展路径；创建自己的 ERP 是可选项，企业连接和数据共享彼此独立。

## 已验收范围

- 未注册邮箱创建个人账号并接受任务邀请。
- 接受邀请不生成邀请方企业成员身份。
- 任务为空时仍可理解去向并访问其他必要页面。
- 任务负责人调度、任务协作者执行和客户地址最小可见。
- 暂停/结束关系后的任务退回与事件留痕。
- 同一账号建立自己的企业、店铺和库存空间。
- 从任务协作关系发起企业连接。
- 连接建立后默认无库存、成本、订单授权。
- 明确选择连接企业后共享单个货盘。
- 解除连接后立即撤销未来访问。

## 发布判断

本链路可进入测试环境继续使用。对不可信公网开放前仍须完成邮箱验证和真实邮件投递；这一限制不阻断当前受控邀请流程验收。
