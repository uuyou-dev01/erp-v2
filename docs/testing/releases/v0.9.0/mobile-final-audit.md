## 本轮补充修复

手动检查发现到货位置、日期、仓库、发货、退货和备注等控件只有可见文字，但部分没有可由读屏软件识别的控件名称。现已为手机业务表单补齐明确的 `aria-label`；视觉布局未改变，修复后的 production build 与 18 条定向测试重新通过。

## 自动化覆盖的不变量

- 手机登记价格与采购后，采购单和下一待办可被查询。
- 同一移动动作的幂等键不会重复执行业务；旧版本请求被乐观并发保护阻断。
- 商品照片写入正确单件库存；其他账号和撤销设备不能继续读取或写入。
- 内部受托人可开始/完成任务，委托人收到结果通知。
- 外部仓库并发领取只有一名成功；转交、退回、撤回后旧执行人立即失权。
- 通知收件人、企业上下文、深链、已读/已处理和 outbox 去重一致。
- 中、日、英 OCR 与网页读取本地路径通过；Web Push 未配置路径明确降级。
